# 呼和诺尔原生空间资料与区域地形

本资料复用已冻结的月分类矩阵、独立固定窗资格表与既有 Copernicus DSM，不新增遥感调查或现场实测。

- huhe-geometry-index.json：1984年4月—2024年12月489个月，145个月通过原双95%覆盖筛选；未合格值留空。
- huhe-water.geojson / huhe-nodata.geojson：145个真实月水域和120个未观测像元图形，原生0.00025度像元边，不平滑，不插值。全部290项类别月份烧回原始网格21,109,100像元，零差。
- huhe-reference.geojson：既有固定湖窗，源于OSM参考轮廓加250米缓冲；不是某年月岸线、行政区或权属。
- huhe-series.json：与空间分类一致的489个月值，可按同月跨年筛选；面积用原像元地理加权公顷，不用地图平面面积替代。
- regional-terrain.json：既有 GLO-30 DSM 地形源在119.16—119.82E、49.055—49.36N的440×240显示网格，双线性降采样，像元中心位置明确。区域显示间距约百米，不提高原始精度，不是湖底或当前地面。
- huhe-source-checks.json / huhe-independent-geometry-check.json：原始文件校验值、面积对照和几何复核记录。

各湖独立固定窗，不能假定同支流水系。呼和诺尔规模远大于本湖；并列面积曲线必须明示数值刻度。相同月份可比，不代表同样降水、来水、人为干扰或治理条件。冬季/过渡季有冰雪解释限制，图形不是水位、水深、活动安全线。

生成依赖：Python3、NumPy、GDAL/OGR。原始矩阵 window_matrix_huhe_lake.npz、window_matrix_grids.json、independent_monthly_area_quality_1984_2024.csv；地形源 Copernicus_DSM_COG_10_N49_00_E119_00_DEM.tif。完整原始资料不包含在这个网页资产集合里。原始矩阵需按掩膜索引还原分类栅格，以4连通GDAL Polygonize提取类别2与0，再用RasterizeLayer回烧逐像元核验。

## 地图显示投影限制
当前场景把经纬度按49.14°固定纬度换算为局部平面坐标，是可视化近似，不是测量投影。在本区域49.055—49.36°纬度内，仅该固定余弦导致的东西方向比例差约−0.171%至+0.447%；呼和诺尔中心约+0.318%。这不改变原GeoJSON经纬度、原始像元加权面积或路线独立距离计算，但不能直接用屏幕尺寸做工程量测。此范围尚未把椭球/球面近似的所有误差合并为总精度。
