# 统一地理画布影像 v11

所有图像的外部画布都是同一个 EPSG:4326 范围：[119.60319444444445,49.078472222222224,119.77958333333335,49.185972222222226]，1285×1197像素。

**统一画布不等于各期均有全域影像。** 无原始覆盖的部分 alpha=0，不用当前影像补历史、不移动地理位置、不拉伸小范围图去覆盖大范围。地图应将透明区显示为中性背景并标出“本期无影像覆盖”。

已有大范围真彩色：1992-07-05、2007-07-31、2021-07-21 Landsat；2026-08-08 Sentinel-2。
已有稍大范围真彩色：2025-08-04，从已缓存的RGB波段裁片重建，含办公院和三块草地。
其他Sentinel-2：仅湖区小窗，不含办公院，保留真实范围。
历史四期：红波段灰阶，不是真彩色，不使用亮暗直接判断盐度。1987年没有缓存的RGB全域影像。

manifest.json 中 assets.geographic.path 和 history_red_band.src 均为相对于网站 dist 根的路径，不是当前目录文件名。uniform_canvas.scope 标识全域/扩大局部/湖区局部。opaque_fraction 仅指可见覆盖比例，不是质量合格率；云和阴影仍可能显示。

重采样使用 nearest 和精确地理变换。统一显示像素不增加10/20/30米原始数据细节。各传感器辐射显示拉伸不同，不可把色差直接当作生态变化。

执行记录：38景真彩色及4景历史红波段生成完成；84,000个随机目标像元独立反算源索引，RGBA差异0。二值透明通道、透明像元RGB为0检查全部通过。此为像素/地理参照一致性检查，不是现场控制点精度验收。

原始已有PNG、波段、质量掩膜未修改，也没有新增下载或补造年份。构建/检查脚本由研究资料包保留；外部改版使用当前manifest即可，不能把透明部分当成无水或无植被。
